# Fuzzy Path Planner & ML Optimizer

Система автономной навигации робота в динамической среде с препятствиями, построенная на базе нечеткой логики (Fuzzy Logic) и оптимизированная методами машинного обучения (Optuna). Проект демонстрирует инженерный подход к разработке ML-систем, включая строгую валидацию данных и модульную архитектуру.

## ⚙Ключевые особенности
* **ML-Оптимизация:** Автоматический подбор гиперпараметров (границы функций принадлежности и пиковые скорости) с помощью фреймворка `Optuna` для максимизации фитнес-функции.
* **Отказоустойчивость:** Строгая валидация входящих данных сенсоров. Реализованы Fallback-механизмы защиты от аномалий (NaN, Infinity).
* **Модульная архитектура:** Физика среды (`environment.py`), математика принятия решений (`fuzzy_controller.py`) и визуализация (`main.py`) полностью изолированы.
* **Производительность:** Граф вывода `scikit-fuzzy` оптимизирован для предотвращения конфликтов типов при массовых прогонах симуляций.

## Технологии
* **Python 3**
* **ML & Math:** Optuna, scikit-fuzzy, NumPy
* **Визуализация:** Matplotlib
* **QA & CI:** pytest, flake8
